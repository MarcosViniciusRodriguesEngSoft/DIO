História dos computadores

O primeiro computador eletrônico digital foi o ENIAC, criado em 1946. Ele era gigantesco e ocupava uma sala inteira. Desde então, a evolução foi exponencial, passando por mainframes, computadores pessoais e chegando aos smartphones que temos hoje.

Para saber mais, você pode acessar a Wikipédia.

O que são Clients?

O Client (Cliente) é a parte do sistema que faz requisições. Quando você acessa um site pelo seu navegador (Chrome, Firefox, Edge), o seu computador está agindo como um cliente. Ele solicita as informações e as exibe para você.

Exemplos de clientes: Navegadores web, aplicativos de celular e programas de e-mail.

O que são Servers?

O Server (Servidor) é um computador ou sistema que armazena os dados e responde às requisições feitas pelos clientes. Ele "serve" a informação que o cliente pediu.

Quando você digita um endereço no navegador, a requisição viaja pela internet até o servidor, que processa e devolve os arquivos HTML, CSS e imagens. Servidores são apenas computadores velhos (isso é um mito, eles são otimizados para alta performance).

Como é uma estrutura básica de um HTML?

A estrutura básica é composta por:

  1. <!DOCTYPE html>: Informa ao navegador que é um documento HTML5.
  2. <html>: O elemento raiz.
  3. <head>: Contém metadados, título e links para CSS.
  4. <body>: Onde fica todo o conteúdo visível da página.

Fórmulas químicas como a da água (H2O) e potências matemáticas (102) são exemplos de uso das tags sub e sup.

Entendendo a diferença entre listas ordenadas e não ordenadas

A principal diferença está na semântica e na exibição:

  • Listas Não Ordenadas (<ul>): Usadas quando a ordem dos itens não importa. Exibem marcadores (bolinhas).
  • Listas Ordenadas (<ol>): Usadas quando a ordem importa (como um passo a passo). Exibem números.

Exemplo de lista ordenada: Passos para criar um arquivo HTML:

  1. Abrir o VS Code
  2. Criar um arquivo com extensão .html
  3. Escrever o código
